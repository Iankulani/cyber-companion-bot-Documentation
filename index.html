🤖 Cyber Companion Bot

Cyber Companion Bot is an advanced autonomous AI bot built for offensive/defensive security workflows — real-time vulnerability scanning, intelligent log analysis, and automated pentesting scripts. It integrates seamlessly with GitHub Actions, Slack alerts, and provides Telegram notifications. The bot supports reconnaissance modules, exploit suggestion engines, and a modular CLI. Whether you're a red teamer or SOC analyst, Cyber Companion boosts your efficiency with AI-powered insights.

📘 Documentation & Core Features

Modular architecture: Write your own plugins in Python/JS.

AI Threat Intel: uses local LLM for pattern recognition.

Integrations: native webhooks for Slack, Discord, Telegram + X (Twitter) alerts.

Pentest modules: Subdomain enumeration, port scanning, fuzzing, and automatic reporting.

GitHub Action ready: Run scans on every commit or schedule.

# Example: Run quick recon

⚙️ Step-by-Step Installation
  • 1 Clone GitHub Repository
    git clone https://github.com/Iankulani/Cyber-Companion-Bot-v1.0.0.git
  • 2 Navigate to project dir
    cd cyber-bot
  • 3 Set up Python virtual environment (recommended)
    python3 -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
  • 4 Install dependencies
    pip install -r requirements.txt
  • 5 Configure environment variables
    cp .env.example .env
nano .env   # add tokens for Slack/Telegram/GitHub
  • 6 Run Cyber Companion Bot
    python companion.py --start
    → Web UI accessible at http://localhost:8080
  • 7 Test your installation
    cyber-companion --help
Pentest Ready: Pre-integrated nuclei, nmap wrapper. For full pentest suite run ./install-pentest.sh from repo.
